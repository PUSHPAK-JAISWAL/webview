# Security Policy

## Supported Versions

Security fixes are made against the latest published version of this maintained package. Users
should update to the latest version before reporting an issue.

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public issue. Email Pushpak Jaiswal at
[pushpakmjaiswal@gmail.com](mailto:pushpakmjaiswal@gmail.com) with a description, impact, and
reproducible details. Please allow time for acknowledgement and coordinated remediation
before public disclosure.
